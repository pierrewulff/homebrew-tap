# pierrewulff Tap

## How do I install these formulae?

`brew install pierrewulff/tap/<formula>`

Or `brew tap pierrewulff/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "pierrewulff/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
